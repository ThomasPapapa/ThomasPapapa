## 🚀 Featured Project

### **[Elxis – AI Rep Counter](https://play.google.com/store/apps/details?id=com.thomaspap.pullupfitnessbuddycamera)**
A high-performance fitness application that leverages on-device AI to automate workout tracking.
* **AI Rep Counting:** Real-time pose estimation using ML Kit to track 33 body points.
* **AR Highlights:** Custom CameraX implementation with real-time video watermarking and social sharing.
* **Modern UI:** Built entirely with Jetpack Compose following Material 3 guidelines.
* **Performance:** Local-first data processing and optimized multi-stream camera pipelines.
